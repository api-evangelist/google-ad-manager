# Google Ad Manager API

The Google Ad Manager API provides programmatic access to manage Ad Manager data including ad units, companies, orders, placements, line items, creatives, reports, and targeting. It enables publishers to automate their ad operations and integrate Ad Manager with other systems.

## APIs

- **Google Ad Manager API** - Programmatic management of ad inventory, orders, line items, creatives, reports, and targeting for publisher ad operations.

## Artifacts

- [APIs.yml](apis.yml) - API discovery document following the APIs.json specification.
- [OpenAPI](openapi/openapi.yml) - OpenAPI 3.1.0 specification for the Ad Manager API.
- [JSON Schema](json-schema/json-schema.yml) - JSON Schema (draft 2020-12) for API resource models.
- [JSON-LD Context](json-ld/json-ld.yml) - JSON-LD context mapping for linked data interoperability.
